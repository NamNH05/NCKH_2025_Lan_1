## 🔧 Mẫu File Cấu Hình

Folder này chứa các mẫu file `.env` và `.properties` cho tất cả services.

**Hướng dẫn:**
1. Copy file mẫu tương ứng đến folder service
2. Đổi tên từ `xxx.env` → `.env`
3. Điền giá trị thực tế (nếu khác default)
4. Lưu file

---

## Danh Sách Files

| File | Dùng Cho | Vị Trí Thực |
|------|----------|-----------|
| `api-gateway.env` | API Gateway | `api-gateway/.env` |
| `frontend.env` | Frontend | `frontend/web-client/.env` |
| `auth-service.properties` | Auth Service | `backend/auth-service/Nckh-Lu-n/src/main/resources/application.properties` |
| `product-service.properties` | Product Service | `backend/product-service/Tien/Tien/src/main/resources/application.properties` |
| `order-service.properties` | Order Service | `backend/order-service/Nckh-C-ng/src/main/resources/application.properties` |
| `audit-service.properties` | Audit Service | `backend/audit-service/Nckh-Hi-p/src/main/resources/application.properties` |
